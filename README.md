# podexit

Shows which CocoaPods dependencies stop getting updates when CocoaPods trunk goes read-only on
December 2, 2026, and which already ship a Swift package.

Work in progress: nothing is published yet, and this README is replaced by the full one before
the first release. Background: [CocoaPods trunk read-only plan](https://blog.cocoapods.org/CocoaPods-Specs-Repo/).
